# personal-web

个人展示网站与大学课程网页实践，包含个人介绍、技能、证书和学习报告。

## 网站内容

- `index.html`：个人展示主页。
- `assets/`、`css/`、`js/`：网站图片、样式及交互。
- `f25011538/`：课程学习报告网页。
- `.github/workflows/deploy.yml`：GitHub Pages 部署。

## 独立项目

以下应用已拆分至各自仓库，源码、测试和运行文档在对应仓库维护：

- [intermodeller-harmonyos-pc](https://github.com/JZ-HX1/intermodeller-harmonyos-pc)：鸿蒙 PC 原生建模应用。
- [travel-reimbursement-assistant](https://github.com/JZ-HX1/travel-reimbursement-assistant)：差旅报销离线 Python 工具、示例及行业报告。
- [项目文档入口](docs/README.md)。

拆分保留了两个项目各自的 Git 提交历史；本仓库已有历史记录仍可追溯迁移前版本。
