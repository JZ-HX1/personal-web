# MVP验证记录

日期：2026-10-29。数据均为教学合成样例。

## 本地验证

- `python -m unittest discover -s tests -v`：25项测试通过。
- `python examples/demo.py`：正常单据进入待审核状态；缺出差申请、跨项目及制度冲突转人工。
- 乱序CSV按事件时间重建；首次导入5条，再导入新增0条、识别5条重复。

## 重点行为

测试覆盖金额非法值与精度、分摊总额不符、缺件、制度过期/未确认/重叠、输入不被修改、重复事件、整批事务回滚、持久化、跨时区排序、无时区时间拒绝、补交不等于复核、负时长及不存在台账时不创建文件。

## 未完成的生产能力

没有用户登录、财务角色授权、真实ERP/OA适配、票据内容识别或验真、签核执行、支付操作、不可篡改审计日志、定时同步或通知服务。`confirmed`来自本地教学配置，不是经过身份认证的签字。附件只检查类型标签，不读取票据内容。

当前周期统计适用于单次报销链路，使用首次显式里程碑，不处理撤回、重新审批和重开单据的完整状态机。生产对接前应扩展事件模型并补相应测试。

跨平台自动测试配置位于仓库根目录 `.github/workflows/travel-assistant-ci.yml`；线上结果以GitHub Actions实际运行记录为准。
